SKILL ORBIT - PURE STATIC HTML VERSION

This package is a WordPress-free static recreation of https://skillorbits.in/.

Files:
- index.html
- about-us.html
- franchise.html
- contact-us.html
- programs/abacus.html
- programs/vedic-maths.html
- programs/phonics.html
- programs/fun-grammar.html
- assets/style.css
- assets/script.js
- assets/img/*

Features:
- Responsive desktop/tablet/mobile layout
- Animated scroll reveals and staggered cards
- Floating/parallax-style decorative motion
- Animated hero/program imagery
- FAQ accordion
- Mobile navigation
- No PHP or WordPress required

Note: The original site imagery that was publicly accessible is referenced from skillorbits.in for the program/decorative assets. The supplied reference screenshot is used for a few self-contained fallback crops so the visual layout remains usable offline.

Open index.html directly or upload the whole folder to Hostinger/public_html.
